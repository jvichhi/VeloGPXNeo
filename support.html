Common issues

What file types work?

.gpx, .geojson, and .json. Open them from Files, Safari, Mail, or any share sheet and VeloGPX will pick them up.

My route isn’t showing on the map

  • Check the file has actual track points or coordinates — some GPX exports are waypoints-only.
  • Try sharing the file again from Files using the share sheet.
  • Go to Settings → Privacy & Security → Location Services → VeloGPX and make sure it’s set to While Using or Always.

Apple Watch isn’t updating

  • Bluetooth needs to be on for both devices.
  • Open the VeloGPX Watch app once manually before starting a ride.
  • Watch data only syncs after you start a ride on the iPhone.

No POIs showing up

POI data is fetched when the route loads. You need a live internet connection at that point. If you loaded the route offline, pull it up again with Wi-Fi or cellular on.

Battery draining fast

GPS apps are heavy on battery by nature. For longer rides, a handlebar mount and a small power bank go a long way. Turning off background app refresh for apps you’re not using also helps.
